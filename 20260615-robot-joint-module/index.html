ROBOT JOINT MODULE / 01

电机动力来源

负责把电能转换成机械能，决定动力上限与动态能力。

  • 电机负责提供最原始的旋转动力，没有电机，关节无法主动运动。
  • 机器人常用伺服电机，因为不仅要能转，还要能精确控制位置、速度与输出力矩。
  • 高速电机可以做得更小，但直接驱动时往往力矩不够；低速大力矩电机则通常更重、更贵。
  • 系统层面上，电机特性决定关节能否快速响应、频繁启停，并在高带宽控制下保持稳定。
工程判断
小型化、高响应与足够力矩之间存在天然张力，因此电机通常与减速器协同设计。

ROBOT JOINT MODULE / 02

减速器力矩整形

把高速小力矩变成更适合机器人的低速大力矩输出。

  • 减速器的第一作用是降速增矩，让输出轴转得更慢，但能带动更重的负载。
  • 减速器的第二作用是提升输出侧控制分辨率，让电机端小角度变化在输出端更可控。
  • 常见类型包括谐波、RV、行星减速器；其中谐波减速器常用于轻量化、紧凑集成的关节。
  • 减速器同时会引入摩擦、回差、间隙、柔顺性和效率损失，使控制问题更复杂。
工程判断
减速比不是越大越好，必须在输出能力与控制性能之间取平衡。

ROBOT JOINT MODULE / 03

驱动器控制执行

把上层控制目标变成电机可执行的电信号，是算法与硬件之间的桥梁。

  • 电机无法直接理解“转到 30 度”或“保持某个速度”，驱动器负责把目标转换成电流与电压控制。
  • 驱动器承担功率驱动任务，把外部供电转换成适合电机工作的形式。
  • 驱动器承担闭环控制任务，基于编码器反馈实现电流环、速度环和位置环。
  • 驱动器通常还集成过流、过温、故障检测和通信接口管理等保护能力。
工程判断
如果电机决定“能不能动”，驱动器决定的就是“动得好不好”。

ROBOT JOINT MODULE / 04

编码器状态反馈

让关节知道自己转到哪、转得多快，从而形成闭环控制。

  • 编码器负责测量旋转位置，并可进一步估计速度与方向；没有它，系统只能“盲转”。
  • 电机侧编码器主要服务于换相与伺服控制，帮助驱动器高频、精细地掌握电机状态。
  • 输出侧编码器更接近关节实际输出，可直接感知减速器后的真实状态。
  • 高性能关节通常不只依赖电机侧测量，因为减速器并不是理想刚体。
工程判断
一个关注电机本身怎么转，另一个关注关节最终转到了哪里，两者组合提升精度与稳定性。

ROBOT JOINT MODULE / 05

抱闸安全保持

在断电、故障或抗重力场景下，让关节安全刹住并保持姿态。

  • 抱闸通常是电磁制动器，主要用途不是驱动运动，而是让关节在特定情况下保持不动。
  • 典型场景包括断电防止因重力下滑、垂直轴停稳保持，以及故障时安全锁止。
  • 肩关节、肘关节等长期抗重力姿态保持的轴常配置抱闸，以降低设备与安全风险。
  • 并非所有关节都必须集成抱闸，轻量化、小型化和低风险关节可能为了节省空间而省略。
工程判断
抱闸更像按需配置的安全部件，而不是每个关节的绝对标配。
